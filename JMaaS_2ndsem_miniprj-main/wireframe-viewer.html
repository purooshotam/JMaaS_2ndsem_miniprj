KEY NAVIGATION POINTS:
1. Login → Dashboard (Central Hub)
2. From Dashboard → All Modules via Sidebar
3. From Any Module → Sidebar Navigation (Persistent)
4. E-Catalogue → Accessible from Each Module
5. Logout Button → Returns to Login Page
6. Sidebar Collapsible on Mobile

✓ User Journey:

  • User enters login page
  • Provides credentials (demo/demo123)
  • Successful login → Redirects to Dashboard
  • Dashboard acts as central hub with sidebar navigation
  • All modules (Inventory, Billing, Customers, AI, Analytics, Catalogue) accessible from sidebar
  • Each module has logout button
  • Clicking logout → Returns to login page
  • Consistent navigation pattern across all pages
